CampusPulse is a Java console application for managing campus events and student participation. It provides three major modules: Event Management, Registration Management, and Reporting and Analytics. Coordinators can create, view, search, update, and cancel events. Students can register for events, while the system prevents duplicate registrations, invalid input, and overbooking. Event and registration data are persisted in CSV files, and reports show capacity, registrations, and category-wise participation. The project demonstrates Java object-oriented programming, collections, interfaces, layered architecture, validation, exception handling, file I/O, and automated testing. The complete source code, README, statement, design diagrams, installation instructions, and tests are available in the linked GitHub repository.
